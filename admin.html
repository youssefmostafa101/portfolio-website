AVAILABILITY · CONFIG

Working hours.

Update your timezone and hours when you travel. The widget on /onboarding.html picks these up.

How this works:
Save writes to your browser's localStorage — instant on this device, won't sync across browsers.
Download availability.json gives you a file to drop into the repo root and commit. That syncs the config for every visitor.
Clear Local Override wipes localStorage so the live availability.json takes effect again.
